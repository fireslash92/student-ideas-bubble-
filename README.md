# فقاعة أفكار الطلاب

منصة تفاعلية لاستشراف مستقبل **كلية البريمي الجامعية** — مبادرة من **IT Club**.

كل فكرة يطرحها الطالب تظهر على هيئة فقاعة متحركة يكبر حجمها كلما زاد عدد المؤيدين لها.

## المزايا
- فقاعات متحركة ملونة حسب المجال، يكبر حجمها مع التأييد
- إضافة فكرة جديدة، وتأييد الأفكار، وإضافة مقترحات عليها
- اقتراح الأفكار المشابهة عند الكتابة لتقليل التكرار
- البحث والتصفية حسب المجال، وقائمة الأفكار الأكثر تأييدًا
- حالة الفكرة: جديدة، قيد الدراسة، معتمدة، منفذة
- لوحة إشراف: دمج الأفكار المتشابهة، وإخفاء المحتوى غير الملائم، وتقرير قابل للنسخ
- تصميم متجاوب يعمل على الهاتف النقال والحاسوب

## الملفات
- `index.html` — المنصة كاملة في ملف واحد
- `logo-wide.jpg` — شعار IT Club

## ملاحظة عن حفظ البيانات
تحفظ المنصة المشاركات وتشاركها بين الطلبة عبر قاعدة بيانات Claude Artifacts.
عند فتحها من خارج Claude (مثل GitHub Pages) تعمل في **وضع المعاينة** بأمثلة توضيحية، ولا تُحفظ المشاركات.
لتشغيلها مستقلة مع حفظ دائم يلزم ربطها بقاعدة بيانات خارجية (مثل Firebase أو Supabase).

> حجم الفقاعة يعكس مستوى التأييد، وليس بالضرورة قابلية التنفيذ أو أولوية اعتماد المقترح.
